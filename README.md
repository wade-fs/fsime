# 混瞎輸入法 (FS IME)

# 原始來源: [筆劃輸入法][1]
# 用法
- 想法是用全英文鍵盤來進行嘸蝦米＋注音＋倉頡＋筆劃...輸入，所以稱之為混瞎輸入法 (FS IME)
	- 在鍵盤上有英、注、倉、筆劃輸入法四種的符號。
	- 在資料庫表格有嘸蝦米/注音/倉頡/筆劃/符號等資訊，輸入時採用完全比對各個表格。
	- 支援模糊比對，不必完全打對即可出字。
- 鍵盤切換與手勢操作：
	- **全域手勢 (Global Gestures)**：
		- **向左滑**：退格鍵 (Backspace ⌫)。
		- **向右滑**：空格鍵 (Space)。
		- **向上滑**：切換至上一個鍵盤。
		- **向下滑**：切換至下一個鍵盤。
	- **長按空格鍵**：呼叫系統輸入法切換器。
- Shift 模式切換：
	- **點擊 Shift**：循環切換模式：單次大寫 (Single) -> 持續大寫 (Caps Lock) -> 關閉 (Disabled)。
	- **滑動輸入**：可以從 Shift 或 Ctrl 鍵按下後滑動到字母鍵，以便輸入大寫字母或組合鍵 (如 Shift-A, Ctrl-C)。
- 語音與相機辨識：
	- **點擊 🎙 鍵**：啟動語音輸入。
	- **長按 SHIFT 鍵**：啟動語音輸入。
	- **長按 ESC 鍵**：啟動 **手寫辨識模式** (支援繁體中文手寫板)。
	- **長按 🎙 鍵**：啟動 **智慧相機文字辨識 (OCR)**。
		- 自動顯示取景框，精確對準文字後點擊屏幕即可辨識。
		- 支援繁體與簡體中文精準輸入。
	- **長按 ⇱ (Home) 鍵**：啟動 **Barcode 條碼掃描**。
		- 提供專屬橫向取景框，即時自動辨識條碼，辨識後自動輸入並送出 (Enter)。
	- **長按 ⇲ (End) 鍵**：啟動 **QR Code 掃描**。
		- 提供專屬正方形取景框，即時自動辨識 QR Code，辨識後自動輸入並送出 (Enter)。
	- **權限引導**：若無錄音或相機權限，系統會自動導向設定頁面協助開啟。
- 智慧學習與排序：
	- **動態權重**：系統會記住您的選字習慣（包含接續詞與特定組字碼）。
	- **選愈多愈靠前**：選過的字會自動排在首位，修正資料庫預設排序混亂或簡體字優先的問題。
	- **字根提示秘技 (Shortest Code Hint)**：
		- **即時回饋**：選取候選字後，空白鍵會立即顯示該字的最短拆碼（如嘸蝦米縮寫）。
		- **輔助學習**：幫助使用者在輸入過程中自然記住更高效的拆碼方式，提升打字速度。
		- **可設定性**：可在設定介面中隨時開啟或關閉此功能。
- 關聯詞與預測：
	- 支援基於 ngram 的關聯詞預測，輸入後會自動顯示可能的下一個字。
	- 可在設定中選擇「關聯詞優先」。
- 豐富的鍵盤功能：
	- 提供 Full (全功能)、FS (混瞎)、Math (數字/運算)、Stroke (筆劃) 等多種鍵盤。
	- 支援全功能鍵：Tab, ESC, Ctrl, Alt, Del, PageUp/Down, Home/End, 方向鍵等。
	- 支援數字鍵盤與數學運算：包含 `√(a,b)` 運算支援。
	- 支援客製化熱鍵：Ctrl-0 至 Ctrl-9, Ctrl-Q/W/E 等，可自定義輸出字串。
- 其他支援：
	- 支援輸出純繁體、純簡體或繁簡混合。
	- 支援選擇是否啟用筆劃鍵盤 (註：注音與倉頡已整合於 FS 混瞎模式中，不再提供獨立鍵盤)。
	- **真瞎練習 (Blind Practice)**：內建嘸蝦米打字練習功能。
		- 支援多種難度等級：從國小一年級到六年級常用字，以及非常用字、符號等。
		- 提供即時統計：自動計算每分鐘打字速度 (WPM) 與錯誤次數。
		- 具備拆碼提示：練習時可自動顯示目標字的拆碼，幫助記憶。

# 數字鍵盤用法

 要讓 Σ (總和)、∫ (積分)、lim (極限) 以及 derivative (微分)                                      
  這些進階運算符號能夠正確運算，必須依照 MathParser 規定的語法格式輸入。                          
                                                                                                  
  以下是這些運算的輸入規範與範例：                                                                
                                                                                                  
1. Σ (總和)                                                                                     
   * 格式： Σ(變數, 算式, 起始值, 結束值) 或 Σ(變數, 算式, 起始值, 結束值, 步長)                     
   * 範例： Σ(i, i^2, 1, 5)                                                                       
   * 意思： 計算 1² + 2² + 3² + 4² + 5²，結果為 55.0。                                            
                                                                                                  
2. ∫ (積分)                                                                                     
   * 格式： ∫(變數, 算式, 下限, 上限)                                                                
   * 範例： ∫(x, x^2, 0, 1)                                                                       
   * 意思： 計算 x² 從 0 到 1 的定積分，結果為 0.333333。                                         
                                                                                                  
3. lim (極限)                                                                                   
   * 格式： lim(變數->目標值, 算式)                                                                  
   * 範例： lim(x->2, x^2 + 3x)                                                                   
   * 意思： 當 x 趨近於 2 時，算式的極限值，結果為 10.0。                                         
   * 注意： 輸入時中間要用 -> (由 - 與 > 組成)。                                                  
                                                                                                  
4. derivative (微分)                                                                            
   * 格式： derivative(變數, 算式, 點)                                                               
   * 範例： derivative(x, x^3, 2)                                                                 
   * 意思： 計算 x³ 在 $x=2$ 處的一階導數（斜率），結果為 12.0。
