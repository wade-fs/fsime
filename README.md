# 原始來源: [筆劃輸入法][1]
# 用法
- 想法是用全英文鍵盤來進行嘸蝦米＋注音＋倉頡＋筆劃...輸入，所以稱之為混瞎輸入法 (FS IME)
	- 在鍵盤上有英、注、倉、筆劃輸入法四種的符號。
	- 在資料庫表格有嘸蝦米/注音/倉頡/筆劃/符號等資訊，輸入時採用完全比對各個表格。
	- 支援模糊比對，不必完全打對即可出字。
- 鍵盤切換與手勢操作：
	- **全域手勢 (Global Gestures)**：
		- **向左滑**：退格鍵 (Backspace ⌫)。
		- **向右滑**：空格鍵 (Space)。
		- **向上滑**：切換至上一個鍵盤。
		- **向下滑**：切換至下一個鍵盤。
	- **長按空格鍵**：呼叫系統輸入法切換器。
- Shift 模式切換：
	- **點擊 Shift**：循環切換模式：單次大寫 (Single) -> 持續大寫 (Caps Lock) -> 關閉 (Disabled)。
	- **滑動輸入**：可以從 Shift 或 Ctrl 鍵按下後滑動到字母鍵，以便輸入大寫字母或組合鍵 (如 Shift-A, Ctrl-C)。
- 語音與手寫輸入：
	- **點擊 🎙 鍵**：啟動語音輸入。
	- **長按 🎙 或 ESC 鍵**：啟動手寫辨識模式 (支援繁體中文)。
- 關聯詞與預測：
	- 支援基於 ngram 的關聯詞預測，輸入後會自動顯示可能的下一個字。
	- 可在設定中選擇「關聯詞優先」。
- 豐富的鍵盤功能：
	- 提供 Full (全功能)、FS (混瞎)、Pure (純瞎)、Math (數字/運算)、Stroke (筆劃) 等多種鍵盤。
	- 支援全功能鍵：Tab, ESC, Ctrl, Alt, Del, PageUp/Down, Home/End, 方向鍵等。
	- 支援數字鍵盤與數學運算：包含 `√(a,b)` 運算支援。
	- 支援客製化熱鍵：Ctrl-0 至 Ctrl-9, Ctrl-Q/W/E 等，可自定義輸出字串。
- 其他支援：
	- 支援輸出純繁體、純簡體或繁簡混合。
	- 支援選擇是否啟用筆劃鍵盤 (註：注音與倉頡已整合於 FS 混瞎模式中，不再提供獨立鍵盤)。
